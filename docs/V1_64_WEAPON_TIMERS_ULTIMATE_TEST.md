- **Rangement :** trois lignes lames de Strife / pistolets de Strife / épée de War, chacune avec « Never automatically sheathe » et délai 0–300 secondes, curseur/saisie/Default. CombatIdleDurationSec +CD0 pilote les lames de Strife ou l'épée de War ; RangedIdleDurationSec +CD4 pilote les pistolets. Les armes à distance de War restent natives. Les deux baselines sont suivies séparément : une modification native d'un champ ne contamine pas la restauration de l'autre. Les raccourcis clavier/manette/Hotkeys appellent toujours les deux fonctions natives Clear une seule fois, sous les mêmes conditions d'attente, de joueur et d'idle. Aucune nouvelle interception pour le rangement, aucun timer écoulé, état de combat, mesh/socket ou input forcé.
- **Compatibilité INI :** les anciennes clés `NeverAutoSheathe` / `SheathDelaySeconds` deviennent les réglages des pistolets et sont conservées. En l'absence des nouvelles clés War, son réglage hérite de l'ancien réglage personnel ; par exemple 30 s reste 30 s pour War et les pistolets. Les lames de Strife démarrent à **0 s / Never OFF**, seuil natif 0 s vérifié dans le relevé V1.59 avant contrôle du mod. Les valeurs modifiées dans le jeu ne sont pas réimportées dans le profil fourni. INI utilisateur non écrit par l'agent. Le contrôle global reste facultatif ; OFF restaure les baselines natives. Quatre nouvelles clés pour les deux catégories ajoutées ; pistolets et War ne partagent plus leur valeur une fois enregistrés.
- **Ultimate decrease rate :** option facultative OFF par défaut, multiplicateur de durée **2 par défaut**, réglable 0–10, saisie et Default ; nouvelle action Hotkeys ajoutée à l'identifiant **52**, sans changer 0–51 ni attribuer de touche. 0.5 = durée divisée par deux, 1 = native, 2 = doublée, 10 = décuplée. **0 consomme le reste au prochain tick natif de décharge positive**, pas Unlimited ; un débit natif nul reste nul. Unlimited Ultimate conserve sa priorité dans le setter existant. Fonctionne pour les acteurs locaux reconnus P1/P2, War et Strife, sous forme active, hors pause/cinématique.
