## Confirmed defects and planned changes
1. CameraReset in DarksidersGenesisMod.cpp 2626-2639 resets BOTH cameras and uses stale TPS Distance=.50, Height=180, FootOrigin=88; shipped defaults are .15, 0, 0, while native global height default is 50 not 0. Split into two actions, `Camera Values Default` and `TPS Camera Values Default`, both assignable to F1-F12 and both visible as buttons. Vanilla numeric defaults FOV90, zoom0, height50, pitch0, yaw0. TPS numeric defaults FOV110, distance.15, pitch-12, height0, foot0, stick speed180; reset orbit yaw/pitch, but never turn TPS OFF as a side effect.
2. Global CAMERA controls currently affect TPS: CameraTraceFeature.cpp HookView adds global yaw and height to TPS (329,345), global FOV applies when TPS FOV OFF (255), HookArm global zoom still operates during TPS (406). ProcessCameraInput and F-key steps modify vanilla settings even during TPS. Fully separate source values and hooks; disable greyed vanilla UI and keyboard camera actions while TPS, preserve native camera saved settings for later. Audit visual height offset (+50 historically added to TPS) before changing framing.
3. `TPSFollowPlayer` checkbox branches attached/nonattached TPS camera and affects RecenterOnPlayer. User wants permanent attachment; retire checkbox, persisted key, runtime field, and nonattached TPS case after preserving fail-open on invalid player/cutscene.
4. TPS camera joystick currently a checkbox that samples Right only; refactor to `OFF / Left stick / Right stick`, Right default, with a safe migration of old boolean. Keep native movement bits untouched, avoid unintended native stick suppression when OFF and keep LB radial native priority. Using Left for camera necessarily shares stick with movement unless separate policy is explicitly tested.
5. R3 = USE currently assigned native continuous hold + 100ms UP + 200ms second stow press in ApplyHoldGrenadeVirtualR3 (2823-2887). Do NOT alter validated hold/stow/pulse or temporary vanilla view after 300ms. Fix erroneous radial classification of R3 in input (2945 and UpdateOrbitInput 3578,3900). Keyboard E is USE, NOT wheel. Delete WheelE/WheelAlt detectors and retired INI keys. Keep and rename only G Equipment Wheel and Tab Ammunition/Abilities Wheel; LB remains pad wheel. Preserve G/Tab custom bindings in migration.
6. DPad Up/Left/Right already offered as single-button choices for mod shortcuts but there is no native equipment wheel 3-direction remap in source. LB fast path forwards original buttons to game; do not inject speculative DPad mapping unless in-game directional selection demonstrably fails.
7. Every keybind should have individual Default: menu, F1–F12 action slots, 8 normal camera keys, TPS keyboard mappings (including horse), controller masks including R3/L3, horse chord, fire/wheel. Preserve intentional Z/Z shared TPS binding; never reset unrelated custom mapping. Existing camera keys have CONFLICTING defaults: ConfigStore.h field initializer vs Store constructor/ResetDefaults; authoritative real defaults are Up/Down height, PageUp/PageDown zoom, Home/End pitch, Left/Right yaw. Current OverlayUi help text incorrectly describes arrows/Numpad.
8. Three distinct always-visible gauge rows, each with slider + manually typed numeric InputFloat + Default x2.00 + checkbox, clamped finite range x1–25, persisted. The V1.02 controls are collapsed and no true Wrath/Ultimate/Synergy gain native hook exists; do not claim functional gameplay gains. Hotstreak AddJuice is not one of these three.
9. Numeric parsing `ReadFloat` can accept NaN/Inf; several sliders clamp without finite guard. Make camera/manual and gauge values finite before clamping and saving. Centralize defaults for Store ctor/reset/INI/overlay and retain existing custom values through ConfigRevision migration.
10. TPS mouse residue: GetAsyncKeyState(VK_LBUTTON) still occurs in TPS native look hooks and misleading WndProc log says native mouse input gate; remove TPS mouse-driven camera/aim/fire branches only, NOT ImGui mouse/reticle/focus input needed for normal overlay and vanilla game. V1.02 already removed RAW mouse orbit and virtual mouse XInput.
11. Cinematic auto view detection is based on camera pitch/proximity and actor freshness, not native movie/cutscene state; can false-positive or miss. Observe native camera/sequence owner before modifying. Skip Warning V1.02 new 3-entry hook is not proven to suppress actual warning; user's last log actually used V1.01. Do not remove MoviePlayer setup/intro and regress focus.
12. Protect frozen horse zones/sprint, shaders targeting CRCs, Engine.ini adapter, Hide Reticle/HUD, native controller strafe, supported EXE SHA gate. CI currently compiles and ZIP-verifies only, no gameplay test; workflow V1.02 has erroneous V1.01 archive commit message and CMake version is historical metadata.
