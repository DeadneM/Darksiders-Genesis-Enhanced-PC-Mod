## V0.76 intended changes

1. **Temporary vanilla camera hold**: physical controller button R3 (XInput `0x0080`) holds temporary TPS suspension; releases immediately back to the TPS view. Configurable separately via overlay and `[Controls] TPSSuspendButtonMask=128`. `[Features] TPSHoldSuspend=1`. The user's F5 persistent TPS choice remains unchanged; original orbit values are preserved through hold, do not reset the zone yaw reference. System remains fail-open outside gameplay/focus and only affects controller 0.
2. **Long-press TPS toggle**: default L3 (`0x0040`), 650 ms, configurable mask and duration. `TPSHoldToggle=1`, `TPSToggleHoldButtonMask=64`, `TPSToggleHoldMs=650`. Short L3 press must still recenter behind the actor. Long hold toggles TPS without needing a keyboard, regardless of whether TPS was OFF/ON.
3. **Grenade hold R3**: experimental translation of physical R3 into two short native R3 press pulses, once when R3 is pressed (equip), once after release (stow), with a 65ms release gap and a 65/80ms pulse. `TPSGrenadeHold=1`, TPS-focused only. Physical R3 is independently read for the temporary camera behavior. This changes only controller 0's game-facing R3 press, not left/right analog. Because this emulates native toggle logic, user MUST validate in-game that the game responds to these pulses, short presses, gameplay outside TPS, grenade throwing and other character-specific R3 functions. No guarantee that it works everywhere.
4. **Hide native ground-target aim effect in TPS**: opt-in (default ON) `TPSHideGroundAimFx=1`, exact-game signature-guarded native callback at `RVA 0x6DDAD0` reconstructed from V0.61; calls native original with hide=true while TPS (but not held vanilla R3). This ONLY covers `HideGroundTargetingEffect`, not all projectile traces, gun lasers or native throw animations. Evidence/log needed.
5. **Mounted TPS camera stability while shooting**: `TPSHorseStableAimCamera=1`. Camera remains attached to the previously validated native horse pose while actively firing; avoids an unintended brief source-switch to a transient on-foot pose, but only after horse has already been acquired through the proven old V0.70 horse callback. No cached UObject pointers dereferenced, no horse movement or stamina code changes. This is a limited camera-source latch, not a complete native horseback aiming rewrite.
6. **Camera defaults copied from user INI** (for new installs and Reset Defaults; existing INI values persist): `TPSFOVDegrees=110`, `ThirdPersonDistanceMultiplier=0.200`, `ThirdPersonPitchDegrees=-12`, `ThirdPersonHeightOffset=300`, `TPSFootAnchorOffset=0`, `CameraYawDegrees=5`, `CameraHeightOffset=-300`, `CameraStickSpeed=180`, `CameraMouseSensitivity=0.12`. `ThirdPerson=0` for brand-new installs remains the safe default rather than copying user's current activated TPS status; F5 or long-press L3 enables it. `TPSFootAnchorOffset` permitted range `-500..+500`. `ThirdPersonHeightOffset` range `-1000..+1000`: user wrote `-1000..-1000`, which would make a single non-adjustable point, so this is **explicitly interpreted as a +/-1000 request**.
7. **UI naming**: `Rotate on foot while firing (camera-forward shooting)` reflects user-confirmed observable behavior when both controller firing modes were enabled in their V0.75 INI. No changes to validated look hook semantics. Both controller firing settings otherwise retain existing user's INI values.
8. **New logging**: permanent runtime counters for temporary TPS holds, long toggles, virtual R3 down/up and native ground FX suppressed. Fresh log per launch preserved.

### Open issues, NOT silently claimed fixed
- User reports second playable character sporadically flashes its throwable weapon for several frames. No native animation or inventory event evidence yet. The limited R3 input normalization may help only if it is driven by R3, but this does **not** prove or repair arbitrary weapon animation flashes. Do not alter the validated weapon/character swap code on a hunch.
- `HideGroundTargetingEffect` may not cover every TPS aiming visual. Test before claiming that all targeting FX are hidden.
- Mounted shooting stabilization addresses world pose selection only. If native horse camera still changes when aiming, identify actual mounted camera callback in a separate, opt-in experimental hook.

L3 short => recenter, L3 held >= 650ms => TPS toggle only once; other buttons and overlay work. On-foot aiming still works with mouse/controller, mounted camera stays anchored during RT/RB, no changes to other characters' weapons. F5, LB wheel, R3/gamepad #2, Alt-Tab, cutscene, co-op safe. `TPSFootAnchorOffset` accepts both +/-500, `ThirdPersonHeightOffset` +/-1000. If any of these regress, revert to archived V0.75. All features are experimental until user validates them.
